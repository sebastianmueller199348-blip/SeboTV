Anleitung: Supabase in 2 Minuten
  1. Auf supabase.com dein Projekt öffnen → SQL Editor → New query.
  2. Im Tab Setup auf SQL-Schema anzeigen klicken, Inhalt kopieren, einfügen und Run.
  3. Danach Project Settings → API: die anon public (bzw. publishable) Key kopieren.
  4. Hier unter Eigener Supabase-Zugang einfügen, speichern – Status wird grün.
Wie die Synchronisierung funktioniert
Jede Steueraktion (Play, Pause, Spulen, Video, Tempo) geht als Broadcast-Ereignis an alle im Kanal und wird zusätzlich in der Datenbank abgelegt. Der Host bestätigt jede Aktion mit einem Zustands-Rundruf; alle richten ihre Abspielposition daran aus. Weicht ein Gerät um mehr als 0,6 s ab, wird automatisch nachgezogen.
